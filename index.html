☁️ Đồng Bộ Bảo Mật Theo Nhánh /users/{uid} (Firebase Auth + Security Rules)

Mỗi học viên chỉ có quyền đọc/ghi đúng nhánh /users/{uid} của họ; chỉ UID của Admin mới đọc được toàn bộ.

Chưa nhập API Key
💡 Quy trình Bảo mật Phân nhánh /users/{uid}:

1. Trong Firebase Console, vào Authentication ➔ Sign-in method ➔ Bật Email/Password.

2. Dán Realtime DB URL + Web API Key vào ô bên trái và bấm Lưu kết nối.

3. Mỗi học viên sẽ được tạo 1 tài khoản Auth riêng và chỉ đọc/ghi đúng nhánh /users/{uid} của mình.

🛡️ Cấu hình Firebase Realtime Database Security Rules (Chuẩn Bảo Mật /users/{uid})

{
  "rules": {
    "admins": {
      ".read": "auth != null",
      "$adminUid": {
        ".write": "auth != null && (auth.uid === $adminUid || root.child('admins/' + auth.uid).exists())"
      }
    },
    "shared_config": {
      ".read": "auth != null",
      ".write": "auth != null && root.child('admins/' + auth.uid).exists()"
    },
    "users": {
      ".read": "auth != null && root.child('admins/' + auth.uid).exists()",
      ".write": "auth != null && root.child('admins/' + auth.uid).exists()",
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('admins/' + auth.uid).exists())",
        ".write": "auth != null && (auth.uid === $uid || root.child('admins/' + auth.uid).exists())"
      }
    }
  }
}
